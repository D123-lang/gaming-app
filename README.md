# Gaming App

If you have ~5 years of software engineering experience and want to build a gaming app, the **best practical choice** is:

- **Frontend:** React Native (mobile) or Next.js (web)
- **Backend:** Node.js + TypeScript (NestJS or Express)
- **Database:** PostgreSQL
- **Realtime features:** WebSocket (Socket.IO)
- **Auth:** Firebase Auth or Auth0
- **Hosting:** Vercel (frontend) + Render/Railway/AWS (backend)

## Why this is the best balanced option

- Fast development speed
- Large ecosystem and hiring pool
- Strong long-term maintainability
- Easy to scale from MVP to production

## Suggested build order

1. Define game type and core loop
2. Build authentication and player profiles
3. Add matchmaking / lobby
4. Add realtime gameplay events
5. Track scores, leaderboards, and achievements
6. Add analytics, anti-cheat basics, and monitoring
